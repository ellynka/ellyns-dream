ELLYN’S DREAM — PWA

Это версия, которую можно попробовать на iPhone без Xcode.
Функции:
- личные задачи и расписание;
- свободный текст;
- картинка из фото;
- ссылка;
- открытие ссылок;
- отметка выполнения;
- данные хранятся локально в браузере.

Для публикации в интернете файлы нужно разместить на HTTPS-хостинге.
После открытия сайта в Safari: Поделиться → На экран «Домой».

Важно: это PWA-версия для быстрого теста. Напоминания iOS в ней не такие полноценные, как нативные локальные уведомления.
